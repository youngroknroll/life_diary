## 왜 문서가 둘인가

구현 명세만 따라간 1차 작업이 기계장치(그리드 병합·집계·되돌리기)는 옮겼지만
화면 모양은 예전 그대로였다. 명세는 파일 단위 핸드오프 문서라 화면 구성을
다루지 않는다. 시안을 전수 분석해 화면 목록과 반복 컴포넌트를 따로 추린 것이
인벤토리 문서다. 모양의 기준은 그쪽이다.

## 데이터 모델

- `Category.color`를 Material 계열 → 시안 팔레트 → 파스텔로 두 번 옮겼다
  (`0008_sian_category_palette`, `0010_pastel_category_palette`).
- `Tag.color`는 `save()`에서 카테고리 색으로 덮어쓴다. 사용자가 색을 고르면
  같은 카테고리끼리 묶여 읽히는 규칙이 깨진다. `Tag.text_color`는 밝기 기반
  뒤집기를 버리고 고정 잉크를 돌려준다.
- `TimeBlock` 스키마 변경 없음. 슬롯 인덱스 체계(0–143)와 `SLOTS_PER_HOUR = 6`
  그대로.

## 되돌리기 설계

세 리뷰어(도메인 아키텍처·보안·백엔드 TDD)의 지적이 설계를 바꿨다.

- 스냅샷을 단일 슬롯에 두면 탭을 두 개 열었을 때 사용자가 되돌린다고 믿은
  것과 실제가 어긋난다 → 토큰별 dict, 최대 3개, 만료분은 저장 시 쓸어냄
- 복원 시 태그 소유권을 재확인하지 않으면 그사이 지워진 태그로 500이 나거나
  절반만 복원된 상태가 남는다 → 하나라도 막히면 통째로 거절
- 복원 대상은 오직 세션 스냅샷에서만 온다. 요청 본문의 날짜·슬롯을 읽으면
  오래된 스냅샷을 엉뚱한 날짜에 덮어쓸 수 있다

응답 봉투는 기존 `success_response` 관례(최상위 flat)를 유지했다. 중첩으로
바꾸면 tags API까지 계약이 바뀐다.

## 접근성

Lighthouse 실측(크롬 MCP)이 잡은 것들.

- 태그 배지가 흰 글자를 써서 3.8:1 → 고정 잉크로 교체
- `text-info`(`#0dcaf0`)가 흰 배경에서 1.96:1 → 라이트/다크를 갈랐다
- 아이콘만 있는 버튼 2개의 이름 누락, 날짜 입력·언어 선택 라벨 누락
- `main` 랜드마크와 meta description 부재
- 기록 그리드에 키보드 경로가 아예 없었다. 방향키 이동 + Shift 범위 확장 +
  Enter/Space 선택을 넣었다
- 공용 `showNotification`이 스크린리더에 아무것도 남기지 않았다 →
  `role`/`aria-live` 부착. 저장·삭제·되돌리기 실패가 전부 이 경로였다

결과: 대시보드 접근성 76 → 96(남은 감점은 데스크톱 19px 타깃 하나),
분석 화면 100, agentic-browsing 50 → 100, SEO 54 → 100.

성능은 손대지 않았다 — 대시보드 LCP 165ms, 분석 401ms, CLS 둘 다 0.00.

## 성능 예산

`test_stats_perf.py`의 쿼리 목표를 6 → 16으로 올렸다. 늘어난 10개는 전부
상수이며 기록량에 따라 늘지 않는다.

- 12주 기준선을 주마다 조회하던 것(12쿼리)을 한 번에 읽고 주 단위로 나눔
- 종료일이 같으면 값이 같은 기준선·스파크라인은 `with_trend=False`로 중복 제거
- 카테고리 비중은 지난 7일 조회 하나를 태그 합과 함께 쓴다.
  `find_by_date_range`가 `tag__category`까지 가져온다 — 빼면 태그마다 조회가
  한 번씩 더 난다

## i18n 함정

이 작업에서만 fuzzy 오염이 세 번 났고 전부 화면을 눈으로 본 뒤에야 발견했다.
`makemessages`의 fuzzy 매칭이 비슷하게 생긴 다른 문자열의 번역을 물려주고,
`compilemessages`는 fuzzy 항목을 통째로 건너뛰어 화면에 원문이 그대로 나온다.

실제 사례: `기록` → `기록률`, `설정` → `수정`, `일` → `일간`, `분석` → `0m`,
`%(tag)s %(hours)s시간` → 인자가 빠진 `%(hours)s시간`.

`apps/core/test_message_catalogs.py`에 계약 테스트 3종을 넣어 자동으로
잡는다 — fuzzy 잔존, ko 항등 위반, 서식 인자 손실. Red-Green으로 확인했다.

## 테스트 방침 변경

사용자 지시로 프론트엔드는 테스트하지 않는다. 렌더 마크업 문자열·CSS 규칙·
JS 소스 문자열을 assert 하던 테스트를 제거했다(총 12건). 계약이 아니라
구현을 따라다녀 재작성마다 깨졌다. `AGENTS.md` Frontend Work Policy에
명문화했다.

- 웹폰트(Pretendard·IBM Plex Mono) CDN 탑재 여부. CSP `font-src`는 jsdelivr을
  이미 허용하므로 SRI만 붙이면 된다. 지금은 토큰 스택만이라 설치 안 된
  환경에서 `system-ui`로 떨어진다
- `Tag.color` 컬럼 드롭 여부. 카테고리 색을 복제만 한다
- 시안 6a의 행 끌어 순서 바꾸기. 순서를 저장할 필드가 없다
- 데스크톱 슬롯 19px의 WCAG 2.5.8 격차 — 밀도를 포기할지 결정 필요
