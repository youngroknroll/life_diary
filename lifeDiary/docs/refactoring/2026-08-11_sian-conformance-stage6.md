# 시안 정합 재작업 6단계 실행 로그

계획: `docs/plans/2026-08-10_sian-conformance-remediation-plan.md`
범위: B3 (빈 상태) + A3 (온보딩 6e)
커밋: `73f1bc0` · `bf59ce2` · `a82de4c`

이 로그는 구현 직후가 아니라 **7단계 착수 시점에 뒤늦게 썼다.** 세 커밋이
나갈 때까지 실행 로그가 없었고, 계획서의 게이트 상태도 비어 있어 다음 사람이
"미착수"로 읽을 상태였다.

## 한 것

### STEP1 — 정적 칩을 실제 체크리스트로

시안 6e 의 첫 화면은 "쓸 태그 고르기"다. 현재는 클릭해도 아무 일도 없는
장식용 칩이었다.

카테고리별로 묶은 네이티브 체크박스(`.chip--pick`, 44px)로 바꾸고 고른 개수를
`role="status" aria-live="polite"` 로 세어 준다. `직접 추가` 는 기록 화면과
같은 모달을 연다 — 온보딩 전용 폼을 만들면 이름 길이·카테고리 필수 규칙이
두 벌로 갈린다.

**아무것도 저장하지 않는다.** 고르지 않은 태그를 지우려면 제품을 한 번도 못
본 사람에게 첫 화면부터 되돌릴 수 없는 삭제를 시키는 셈이고, 순서만 바꾸려
해도 `Tag.display_order` 가 그때는 없었다(7단계에서 생겼다). 지금은 무엇을
쓸지 눈으로 확인하는 자리다.

### STEP2 — `aria-hidden` 데모를 진짜 기록으로

시안은 STEP2 에서 실제로 한 구간을 채우게 한다. 현재는 스크린리더에서
숨겨진 가짜 그리드였다.

기록 화면의 24시간 그리드를 **그대로 빌려 쓴다.** `dashboard.js` 는 975줄이고
프론트에는 자동 테스트가 없다. 공유 모듈로 쪼개는 것보다 마크업과 널 가드를
맞추는 쪽이 위험이 낮다. 더한 것은 둘뿐이다 — 없는 요소에 대한 널 가드,
그리고 저장 성공 후의 `time-blocks-saved` 이벤트.

### STEP3 — select 3개를 스테퍼와 미리보기로

기간은 라디오, 목표 시간은 `− 4.0 +` 스테퍼(44×44, 0.5~24 클램프).
미리보기의 **분자는 언제나 0** 이고 `예시입니다` 캡션을 달았다 — 이 시점에는
목표도 기록도 없어서 실측처럼 보이는 숫자를 지어낼 수 없다.

`방금 기록 취소` 는 STEP2 에서 실수로 채운 구간을 무른다. 되돌리기 토큰의
수명이 60초뿐이라(`apps/dashboard/undo.py`) STEP3 에서 잠깐 머뭇거리면
만료된다. 그래서 토큰이 아니라 `sessionStorage` 에 적어 둔 슬롯을 지운다.

## 리뷰

STEP1 은 **사전 산출물 없이 시작했다.** 5단계 로그의 "6단계부터는 사전
산출물을 먼저 받는다"를 지키지 못했다. STEP2·STEP3 은 사전·사후를 모두 받았다.

### 사후 판정이 잡은 진짜 결함

**저장에 아무 피드백이 없었다** (상호작용 Medium). `showUndoSnackbar` 가
온보딩에 없는 `#undoSnackbar` 를 찾지 못해 조용히 빠져나갔고, 성공 경로에서
`showNotification` 도 부르지 않은 채 곧바로 페이지가 넘어갔다. 눈으로 보는
사람은 화면 전환으로 짐작하지만 **스크린리더 사용자는 저장됐다는 사실을 전혀
알 수 없었다.**

스낵바가 없으면 토스트로 떨어지게 하고, STEP3 도착 시점에
`<p role="status">방금 채운 구간을 저장했습니다.</p>` 를 두어 끊긴 고리를
이었다.

### 경험 명세가 잡은 4건

- 제목과 동작 불일치 — 칩이 전부 체크된 채 시작하는데 "골라볼까요"는 없는
  선택권을 판다. `쓸 태그를 확인해 볼까요` 로
- `.onboarding__grid` 의 `max-height: 46vh; overflow-y: auto` — 스크롤하는
  페이지 안의 중첩 스크롤이고 기록 화면에 전례가 없다. 제거
- 비어 있던 한국어 `msgstr` 46건
- 폐기된 `.onboarding__demo*` CSS 34줄

## 구현 중 잡은 것

- **fuzzy 오역 8건.** `지금 시각 %(t)s` 가 `지금 시각 채우기` 를 물려받아
  시각을 통째로 삼킬 뻔했고, `목표 시간 30분 늘리기` 가 `목표 시간` 을
  물려받았다. 전부 플래그를 걷기 전에 잡았다
- **여러 줄 `{# #}` 주석이 페이지에 그대로 찍혔다** — 세 번 반복된 뒤
  저장소 전수 점검을 돌렸고, 3단계부터 새던 `usergoal_list.html` 의 것도
  나왔다. 전부 `{% comment %}` 로 바꿨다. Django 의 주석 토크나이저 정규식은
  `DOTALL` 이 아니다
- **`#saveBtn` 이 아무 일도 하지 않았다** — 기록 화면은 저장을
  `onclick="saveSlot()"` 로 건다. 내 버튼에는 그게 없었다
- **`apiCall is not defined`** — 인라인 스크립트가 `defer` 된 `utils.js` 보다
  먼저 돌았다. `DOMContentLoaded` 로 감쌌다
- **`apps/users/views.py` 의 `timezone` 미임포트** — `manage.py check` 는 뷰
  본문을 실행하지 않아 보이지 않았다
