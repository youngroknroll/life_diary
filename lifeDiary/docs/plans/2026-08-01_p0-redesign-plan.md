## 2·3단계 완료 내역

마크업이 슬롯 144개에서 run 블록으로 바뀌면 기존 드래그 JS가 즉시 깨지므로
두 단계를 함께 반영했다.

- `services.build_slot_rows()` 신설 — 슬롯 144개를 24행 × 6열로 묶고 같은 태그
  연속 칸을 하나의 run 으로 병합한다. 병합은 뷰가 아니라 여기서 하며 저장 후
  부분 갱신도 이 함수를 재사용할 수 있다. `test_slot_rows.py` 12건이 규칙을
  고정한다.
- 라벨 규칙 — 3칸(30분) 이상일 때만, 여러 시간에 걸친 구간은 한 번만. 첫 행
  조각이 3칸에 못 미치면 라벨이 통째로 사라지므로 **폭이 충분한 첫 행이 대신
  받는다**(명세 문구를 그대로 따르면 13:40–15:00 같은 구간의 라벨이 사라진다).
  3글자 자르기와 `text-shadow` 는 삭제했다.
- `build_time_headers()` 가 12칸 → 6칸(`:00 … :50`)으로 바뀌었다.
  `.time-header-cell:nth-child(n+7){display:none}` 규칙도 함께 삭제.
- CSS `.time-grid`/`.time-slot` → `.day-grid`/`.day-row`/`.slot-block`.
  열 수는 화면 폭과 무관하게 6 고정, 모바일은 라벨 40px·블록 22px.
- 드래그를 그리드 하나에 위임했다. 슬롯마다 붙어 있던 `onclick`·`onmousedown`
  ·`onmouseenter`·`ontouchstart` 인라인 핸들러를 전부 걷어내고
  `pointerdown/move/up/cancel` + `setPointerCapture` 로 통합했다. 표시 블록이
  여러 칸을 덮으므로 슬롯은 좌표로 계산한다(`slotFromPoint`).
- 선택 표시는 `.day-row__selection` 오버레이에 그린다. 연속된 칸은 하나의
  덩어리로 합쳐 시안의 선택 표시와 맞췄고, 표시용 run 블록은 건드리지 않는다.
- 모바일 세로 스와이프는 `.day-grid` 의 `touch-action: pan-y` 가 스크롤로
  가져가고, 그때 오는 `pointercancel` 에서 진행 중이던 선택을 확정하지 않는다.
  기존 touchmove/preventDefault 소스 문자열을 검사하던 테스트 2건은 이 계약을
  검사하도록 다시 썼다.

## 결정 사항 (2026-08-01 확정)

명세 §7의 미결정 3건에 대한 사용자 결정.

1. **직전 동일 기간 집계 추가한다.** `comparison.py`를 신설해 증감·스파크
   라인·기준선(4주 평균·12주 최고)을 모두 살린다. 시안의 분석 화면을
   축소하지 않는다.
2. **주 기간은 달력 주(월~일)를 유지한다.** 시안은 롤링 7일 기준이므로
   여기서만 시안과 갈린다. 따라오는 두 가지를 5단계에서 함께 정해야 한다.
   - 진행 중인 주의 부분 합계 표기 규칙 — 일요일이 오지 않은 주의 합계를
     완료된 주와 같은 자리에 두면 항상 낮게 읽힌다. 경과일 기준 분모를
     쓰거나 "진행 중" 라벨을 붙인다.
   - 요약 탭(4a)의 "지난 7일" 카드 — 롤링 표현이므로 "이번 주"로 바꿀지,
     요약 카드만 롤링으로 남길지. `weekly.py`는 `rolling=True`로 바꾸지
     않는다.
3. **시안대로 간다.** 로그인 후 진입점을 홈 → 오늘 기록으로 바꾸고,
   모바일 하단 탭바(기록·분석·설정)를 도입한다. 홈은 비로그인 방문자
   전용이 된다(5a). 태그 관리는 최상위에서 설정 하위로 내린다.

## 카테고리 팔레트 정합 (시안 섹션 7)

명세는 turn 1–4 기준이라 이 항목이 빠져 있다. 확인 결과 **모델 변경은 필요
없다** — `apps/tags/models.py`의 `Category`가 이미 시스템 고정 5분류이고
`Tag.category`는 필수 FK다. 실제 차이는 두 가지뿐이다.

- `0005_seed_categories`의 색이 Material 계열(`#9E9E9E` `#4CAF50` `#2196F3`
  `#FF9800` `#673AB7`)이라 시안 팔레트와 다르다 → 데이터 마이그레이션으로
  갱신
- `Tag.color`가 아직 태그별로 쓰인다. 시안은 색을 카테고리가 정하고 태그별
  색 선택기를 없앤다(7b) → 색 해석을 `tag.category.color`로 옮기고
  `_tag_modal.html`의 색 선택기·추천 스와치 제거. `Tag.color` 컬럼 자체를
  드롭할지는 별도 판단(당장은 미사용 상태로 두는 편이 안전)

`Tag.text_color`가 `self.color`에 의존하므로 함께 옮겨야 한다.
