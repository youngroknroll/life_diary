# 시안 화면 인벤토리와 공통 스펙

`Life Diary P0 시안.dc.html`을 전수 분석해 화면 목록과 반복 컴포넌트를 추렸다.
구현 명세(`Life Diary P0 구현 명세.dc.html`)는 기계장치 핸드오프 문서라 화면
구성을 다루지 않는다. 모양의 기준은 이 문서다.

## 공통 크롬

시안의 760px·1280px 화면이 모두 같은 헤더를 쓴다(6a·6c·6d·5a·5c).

```
높이 56px · 좌우 24px · 아래 경계 1px #E3E6E1 · 배경 #fff
  브랜드   700 15px #2C6E4A
  좌측 gap 26px, 탭 사이 gap 4px
  탭      400 13.5px #4C5B52 · padding 7px 12px
  활성 탭  500 13.5px #14211A · 배경 #EDF3EE · radius 7px
  아바타   28px 원 · 배경 #EDF3EE · 글자 600 11px #2C6E4A
```

최상위는 **기록 · 분석 · 설정** 셋뿐이다. 태그 관리는 설정 하위로, 언어와
테마도 설정 안으로 들어간다(5c·6b). 모바일은 하단 탭바 58px.

## 타이포 스케일

시안은 본문 색을 네 단계로 쓴다. 지금 코드는 두 단계뿐이라 위계가 뭉갠다.

| 역할 | 색 | 용례 |
|---|---|---|
| 제목·수치 | `#14211A` | 페이지 제목, 타일 수치, 표 데이터 |
| 본문 | `#4C5B52` | 설명 문장, 탭 비활성 라벨 |
| 보조 | `#6C7A70` | 부제, 캡션, 표 헤더 |
| 메타 | `#8B968D` | 단위, 근거 한 줄, 기준일 |

크기는 `19 / 18 / 16 / 14 / 13.5 / 13 / 12.5 / 12 / 11.5 / 10.5px`을 쓴다.
수치와 시각은 모두 모노스페이스(IBM Plex Mono)다 — 시안에서 mono 조합이
100회 넘게 나온다.

## 반복 컴포넌트

- **섹션 제목** — `600 12.5px #14211A` + 뒤에 `400 11px #8B968D` 부연.
  카드 헤더가 아니라 본문 안의 소제목이다. 시안에는 Bootstrap `card-header`가
  단 한 번도 없다.
- **수치 타일** — 4열 그리드, `gap:1px` + 배경 `#EDEFEB`으로 경계선을 만든다.
  타일 `padding 12px 14px`, 라벨 `500 10.5px mono #6C7A70`,
  값 `600 22px mono #14211A letter-spacing -.02em`, 주석 `400 10.5px #8B968D`.
- **관찰 행** — 좌측 3px 색 막대(태그 색) + 헤드라인 `500 12.5px #14211A` +
  근거 `400 11px mono #8B968D`. 행 사이 `1px #F2F4F1`.
- **태그 칩** — 높이 32~38px, `padding 0 11px`, `border 1px #E3E6E1`,
  `radius 16px`, 글자 `400 12px`, 색 스와치 `10px radius 3px`.
- **세그먼트 컨트롤** — 배경 `#F1F3F0` radius 8px padding 3px,
  활성 항목만 흰 배경 + radius 6px + `500 12px`.
- **기본 버튼** — 배경 `#2C6E4A`, radius 8~9px, `600 12.5~13.5px #fff`,
  `padding 9px 14px`. 보조는 `border 1px #E3E6E1` + `500 13.5px #4C5B52`.
- **빈 구간·트랙** — `#F1F3F0`. 밀도 0단계는 `#E7EAE6`.
- **위험** — `#B4471F`(글자), 파괴적 확인은 `#8A3A18` 배경.

## 시안과 갈린 지점

- **주 기간** — 시안은 롤링 7일, 우리는 달력 주(월~일). 사용자 결정.
  진행 중인 주는 `is_partial`과 경과일 분모로 정직하게 표기한다.
- **카테고리 색** — 시안 팔레트(#4E8F63 계열)가 어둡다는 판단으로 채도 높은
  파스텔로 교체. 회색은 미분류 전용이라 수면은 연보라를 받는다.
- **잉크** — 시안의 `#14211A`는 일부 accent에서 4.5:1에 못 미쳐 `#0F1A14`.
- **홈 kicker** — 시안 5a의 "하루 10분 단위 기록"을 채택. 홈에서 10분 단위를
  감추던 2026-04-11 결정을 뒤집었다.
- **데스크톱 슬롯 높이** — 시안 19px 유지. WCAG 2.5.8(24px)에는 미달이며
  `pointer: coarse`에서만 24px로 올린다. 밀도와 기준 사이의 알려진 격차.
- **7d 목표 추가 모달** — 별도 모달 대신 설정의 인라인 폼과 온보딩 3스텝에서
  같은 일을 한다. 모달을 하나 더 만들지 않았다.
- **7c 카테고리 비중** — 별도 520px 패널이 아니라 요약 탭 안에 넣었다.
  기간 컨트롤을 두 벌 두지 않기 위해서다.
